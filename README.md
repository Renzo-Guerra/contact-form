📬 ContactForm Component

A fully functional and validated contact form built with React, TypeScript, React Hook Form, Zod, and React Hot Toast.
It demonstrates how to handle form validation, submission states, and user feedback with modern React libraries.

* 🚀 Features

* ✅ Built with TypeScript for full type safety

* 🔒 Client-side validation powered by Zod

* ⚡ Uses React Hook Form for optimized form handling

* 🧠 Displays validation and submission feedback with React Hot Toast

* 🎨 Styled with Tailwind CSS

* 🔁 Automatic reset after successful submission
